# Android 预览版测试步骤（给用户）

本文是操作手册。**跟着做就行，出问题按 §5 对照表把指定文本发回来。**

- 包名（用来在系统设置里找它）：`io.github.huang404yan.platypus.launcher.preview`
- 版本：`0.8.0-preview.1`（`versionCode 80001`）
- 当前能力：**能列版本、能下载游戏文件、能建实例、能自检环境。不能启动游戏**（S1 还没做完）。

---

## 1. 装哪个包

| | |
|---|---|
| 文件 | `releases/preview/android/Platypus-Launcher-0.8.0-preview.1-android.apk` |
| 大小 | 12,772,675 B（约 12.2 MB） |
| sha256 | `5b18650fb2421c2a1f7d2eee5bf31b01fa7e671512df3f09aec194d573b37aa7` |

如果这个包是通过微信/QQ/网盘传的，**先确认大小对不对**（12.2 MB）。这些渠道偶尔会改文件。

装的时候系统会拦：

1. 「未知来源应用」提示 → 允许你用的文件管理器/浏览器「安装未知应用」。
2. 某些机型（小米/OPPO/vivo）会报「风险应用」→ 选「仍然安装」。
3. 装完**不要点「打开」直接进**，先去设置里给权限（见 §2），否则第一次进会白屏或读不到目录。

## 2. 开权限（这一步不做，后面全废）

应用需要两个权限，缺任何一个都会在读游戏目录时失败：

### 2.1 「所有文件访问权限」（必须）

1. 打开应用 → 底部/左侧「实例」页 → 如果看到红字提示「未授权」和「去授权」按钮，**直接点「去授权」**。
2. 会跳到系统的「所有文件访问权限」页面 → 打开开关 → 返回。
3. 如果「去授权」跳转失败（某些 ROM 改了这个 Intent），手动走：
   **设置 → 应用 → 鸭嘴兽启动器 → 权限 → 所有文件访问权限**（有的机型叫「文件和媒体」→「允许管理所有文件」）。

> 为什么必须给：Minecraft 的游戏文件（`.minecraft`）在手机存储里，Android 11 以后普通应用只能看自己沙盒，读不到 `/storage/emulated/0`。这不是「可选权限」。

### 2.2 网络（一般自动有）

`INTERNET` 是普通权限，装完就有。如果 §4 的网络探测显示失败，去看是不是开了飞行模式或者用了有认证的 Wi-Fi。

---

## 3. 三步验证

按顺序做，**每一步都记下看到什么**。

### 第一步：诊断页（先做这个）

1. 左侧竖排标签里点「**诊断**」。
2. 页面会自动开始检测，等进度条走完（约 3–10 秒，网络和 EGL 两项最慢）。
3. 检查这几项，**任何一项是红色就是问题**：

| 分节 | 该看到什么 |
|---|---|
| 存储 | 「所有文件访问权限」= 已授权；根目录「存在」；写入探针「成功」 |
| 内存 | 堆上限 ≥ 1 GB |
| 网络 | 版本清单探测 HTTP **200**；资源站探测 HTTP **403 或 404**（这俩都算通，因为我们故意请求一个不存在的文件） |
| 图形 | GL_RENDERER 有具体名字（不是「获取失败」），扩展总数 > 0 |
| 游戏目录 | 至少一行「存在」；不存在也没关系，第一次跑本来就没有 |

4. **点「复制诊断信息」**，它会显示「已复制 N 个字符」。
5. 粘贴到微信/记事本里存着 —— 这就是 §5 要发回来的东西。

### 第二步：下载页（验证网络与磁盘）

1. 点左侧「**下载**」。
2. 左边那一栏（260 dp 宽的版本列表）会加载，上方显示「共 N 个正式版，显示 N 个」（第一次约 1–3 秒）。**如果这里就报错**，说明网络不通，先别往下做，直接跳到 §5。
3. 在列表里点选一个版本。**建议先选 1.20.1**，原因：它只要 Java 17，是我们唯一确定能凑齐运行环境的版本。
4. 看右栏「目标目录」下面那个输入框（标签是「游戏目录」）显示什么路径，记下来（大概是 `/storage/emulated/0/.minecraft`）。
5. 点「**下载到上面这个目录**」。

**预期现象**：进度条从 0 走到 100%，进度下方显示「文件 N/N · X MB / Y MB · 100%」，最后变成一行「完成：N 个文件，X MB」。
**耗时参考**：706 MiB，Wi-Fi 好约 1–2 分钟，4G 约 6 分钟。

> ⚠️ 这一版**没有断点续传的界面提示**，但已经下了的文件（sha1 对得上）会跳过。所以中断了可以再点一次，不会重下已有文件。

6. 如果失败，界面会显示红字（格式是 `类的全名: 消息`）+ 逐条详情 + 一个「**复制失败信息**」按钮 → **点它，粘贴存下来**。

### 第三步：实例页（验证扫描）

1. 回「**实例**」页。
2. 如果目录框里是空的，点「扫描」。
3. 应该能看到刚才下载的版本出现在列表里（卡片上有版本 id 和一个 loader 标签，原版显示「原版」）。

## 4. 这一版**不能**做什么（别当 bug 报）

| 现象 | 原因 |
|---|---|
| 「启动」页点了没反应 / 只有占位文字 | 正常。启动链路（runtime-android）还没写 |
| 「更多」「关于」页只有说明文字 | 正常，未实现 |
| 下载完点不了「启动游戏」 | 正常，同上 |
| 不能登录 | 正常，未实现 |
| 没有中文输入法在游戏里 | 不适用，游戏起不来 |

## 5. 出问题怎么回报（关键）

**我没有你的手机，也拿不到 logcat。所以界面上的文字就是唯一证据。**

失败时按这个顺序做：

1. **先点「复制失败信息」或「复制诊断信息」**（哪个页出问题就点哪个）。
2. 粘贴到一个地方（微信文件传输助手 / 备忘录 / 发给我）。
3. 再补三句话：
   - 手机型号（如「小米 13」）和 Android 版本（设置 → 关于手机）。
   - 你在哪一步、点了哪个按钮。
   - 屏幕上出现了什么（截图最好）。

### 常见报错对照表

| 界面显示的开头 | 大概率原因 | 怎么办 |
|---|---|---|
| `java.net.UnknownHostException` | DNS 解析失败 | 换 Wi-Fi / 关掉代理 / 关掉「私人 DNS」 |
| `java.net.SocketTimeoutException` | 网络太慢或墙 | 换网络重试；这不是我们的 bug |
| `javax.net.ssl.SSLException` | 系统时间不对，或中间有抓包代理 | 校准时间；关掉 VPN/抓包 |
| `java.io.FileNotFoundException: /storage/emulated/0/... (Permission denied)` | 没给「所有文件访问权限」 | 回 §2.1 |
| `java.io.IOException: No space left on device` | 存储不够（要 1 GB 以上空闲） | 清理空间 |
| `java.lang.SecurityException` | 权限被 ROM 拦了 | 去设置里手动给权限 |
| `kotlinx.coroutines.JobCancellationException` | 你点了「取消」 | 正常，不是错误 |
| `HTTP 403` / `HTTP 404` 出现在资源站探测 | **正常**（我们故意探不存在的文件） | 不用管 |
| `HTTP 5xx` 出现在版本清单 | Mojang 服务器问题 | 过一会儿重试 |

> 界面上的报错格式统一是 `类的全名: 消息`，例如 `java.net.UnknownHostException: Unable to resolve host "piston-meta.mojang.com"`。**请把整行原样发回来，不要截断也不要转述** —— 类名决定了是网络、权限还是磁盘。

## 6. 已知限制（提前说，免得白测）

1. **1.21.1 以后跑不了**：能下载，但跑不起来 —— 它要 Java 21，而上游 Java 运行时的 Android 版只发到 Java 17。这是当前最大缺口，不是这几天的 bug。
2. **下载中断不会自动续**：要手动再点一次（已下的文件会跳过）。
3. **屏幕是横屏锁定**：这是设计如此（将来游戏也是横屏）。
4. **没有深色模式适配**：跟随系统，但配色是固定的一套。
5. **首次启动下载全部文件要 700 MB+**：这不是我们的包大，是 Minecraft 本身的资源文件大。

**装 `releases/preview/android/` 下那个 12.2 MB 的 APK → 给「所有文件访问权限」→ 点「诊断」→ 点「复制诊断信息」→ 发给我。**
就算一切正常，也请把诊断信息发一份 —— 那是我们判断机型差异的唯一依据。
